# Frontier Perspectives website — Start here

Welcome! This package contains everything you need to run the Frontier Perspectives website
yourself. No technical knowledge is needed for day-to-day work.

## What's in this package

| # | Item | Use it when… |
|---|---|---|
| 1 | **This page** | You want to know where everything is. |
| 2 | **Video walkthroughs** (folder) | You want to *see* how to do something — 2-minute videos, one task each. |
| 3 | **Owner's Guide** (PDF) | You want step-by-step instructions or an answer to "How do I…?" (about 70 questions answered). |
| 4 | **Ask-AI-for-help** (PDF) | Something isn't covered — copy the prompt into ChatGPT, Claude or Gemini. |

| 7 | **Website code** (zip) | Backup copy of the custom code. The master copy is on GitHub (see below). |

## Your first 30 minutes
1. Log in at **frontierperspectives.com/wp-admin** and change the password to your own
   (Owner's Guide **C-72**).
2. Watch videos **01 Welcome**, **03 Admin tour** and **04 Adding a job**.
3. Add one real job or scholarship, following video 04 or 06.
4. Open **Messages** in the admin menu and read anything new.

## Your routine
- **Weekly (15–30 min):** check Messages; add new listings. Expired listings disappear from
  the website by themselves.
- **Monthly (15 min):** Dashboard → Updates (see video 21).
- **Every 6 months:** make a backup in Hostinger and download it (Owner's Guide C-91).

## If something goes wrong
1. Don't panic — nothing you do in the admin can break the design, and deleted items stay in
   the **Trash** for 30 days (video 22).
2. Look it up in the **Owner's Guide**, Part C (questions C-60 to C-99 cover problems).
3. Ask an AI assistant with the **Ask-AI-for-help** prompt and the two `.md` files.
4. For anything involving code, give a web developer the **Technical Guide** and GitHub access.
